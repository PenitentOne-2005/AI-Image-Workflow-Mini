# AI Workflow Engine Mini

Минималистичный движок исполнения графов AI-воркфлоу (DAG Engine) с параллельным выполнением узлов, управлением зависимостями и интеграцией генеративных нейросетей.

## 🚀 Особенности и Архитектура

- **DAG Engine (Topological Sort):** Граф задается декларативно через узлы (`nodes`) и связи (`edges`). Бэкенд вычисляет входящие зависимости (`in-degree`) и формирует параллельные батчи исполнения.
- **Параллельное выполнение (Parallel Execution):** Независимые ветки графа (например, `Generate Variant A` и `Generate Variant B`) запускаются одновременно с использованием `Promise.all()`.
- **Изоляция секретов:** Все обращения к AI API происходят исключительно на бэкенде. Фронтенд не имеет доступа к API-ключам.
- **Preset как отдельная сущность:** Пресеты стилей вынесены в Data Model на бэкенде, а не «зашиты» в UI-компоненты. Нода хранит лишь `presetId`, а сборка итогового промпта происходит в процессе выполнения ноды (`processNode`).
- **Обработка ошибок и Retry:** Поддержка состояний (`idle`, `queued`, `running`, `success`, `error`). При сбое отдельного узла доступен перезапуск (`Retry`) конкретной ноды с перезапуском зависимой цепочки.

## 📐 Архитектура графа и Сценарии

В проекте реализовано обязательное ветвление графа:

```text
               ┌──> [ GENERATE (Variant A) ] ──> [ RESULT A ]
[ PROMPT ] ────┤
               └──> [ GENERATE (Variant B) ] ──> [ RESULT B ]
```

### Подход к расширению (Image Input / Edit Image)
Для реализации сценариев редактирования изображений (`Image Input → Edit Image → Result`) архитектура расширяется следующим образом:
1. Добавляется узел типа `imageInput`, принимающий base64/URL исходного изображения.
2. Добавляется узел `editImage`, принимающий на вход две связи (Image Node + Prompt Node).
3. В `processNode` добавляется обработчик для типа `editImage`, который передает в AI API (например, OpenAI DALL-E 2 / Stability Image-to-Image) оба параметра — исходную картинку и маску/текстовое описание изменений.

## 📦 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/PenitentOne-2005/AI-Image-Workflow-Mini
cd AI-Image-Workflow-Mini
```

### 2. Установка зависимостей

Если проект организован как монорепозиторий (или 2 отдельные папки):

```bash
# Установка зависимостей бэкенда
cd backend
npm install

# Установка зависимостей фронтенда
cd frontend
npm install
```

### 3. Запуск в режиме разработки

**Запуск бэкенда:**
```bash
cd backend
npm run dev
```
*Бэкенд будет доступен по адресу `http://localhost:3001`.*

**Запуск фронтенда:**
```bash
cd frontend
npm run dev
```
*Фронтенд будет доступен по адресу `http://localhost:5173`.*
